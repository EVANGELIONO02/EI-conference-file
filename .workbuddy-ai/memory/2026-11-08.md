### 踩坑

1. **Python 环境**：系统 Python 3.13（`C:\Users\ROG\.workbuddy-ai\binaries\python`）**没有** matplotlib/numpy/cairosvg；可用的是 Anaconda `D:\Users\ROG\anaconda3\python.exe`（Python 3.8.3 / matplotlib 3.2.2 / numpy 1.19.2）。所有绘图脚本用后者执行。
2. **噪声曲线不能按 `sqrt(1-ab)` 直接缩放**：那样第二帧曲线就被淹没，看不出"逐步失真"的层次。改为**显式给每帧指定 (信号幅度, 噪声幅度, 噪声高频权重)**，并让高频权重随步数升高（低频平滑噪声 → 白噪声的连续混合），才得到参考图那种"先轻微抖动、后完全失真"的渐进观感。
3. **噪声会被 y 轴裁剪成实心色块**：高噪声帧需软压缩 `y = 1.06*tanh(y/1.06)`，不能靠裁剪。
4. **`range()` 起点写错导致帧序错乱**：反向段用 `for r in range(4)` 却索引 `list[r-1]`，r=0 时取到列表末位（干净帧），出现"第 6 帧反而干净、末段最脏"的倒挂。改 `range(1,5)` 后正常。**教训：显式索引列表时优先用 `zip` 或 `enumerate` 配 `[i]`**。
5. 无 `cairosvg`/`rsvg-convert`/`magick`/`inkscape`；矢量化直接靠 matplotlib 存 SVG/PDF（`svg.fonttype="path"`），PNG 校验用 Chrome/ViewImage。

## 追加：改 16:9 宽屏（用户要求调整画幅比例）

- 画幅从 14.6×3.30 in（4.4:1）改为 **12.8×7.2 in（严格 16:9，输出 3840×2160）**，脚本内 `FIG_W/FIG_H/DPI` 常量控制。
- 宽屏适配的版式重构（**不是简单拉伸**，而是三带重排）：
  - **上/中/下三带**：上=加噪公式色带（跨加噪段）、中=9 个面板的单行条带、下=去噪公式色带（跨去噪段）。长箭头紧贴面板带上下沿（偏移 0.042），公式色块再随之外移 0.132。
  - 面板带**垂直居中**（`p_top = 0.470 + ph*0.5`），使三带整体在画幅内视觉居中。
  - 面板高度用**英寸**给定（`panel_h_in`）而非按比例，保证改画幅时波形不被拉高变形 —— 这是"无拉伸变形"的关键。
  - 外加一层**细圆角外框**（`FancyBboxPatch`，`rounding_size=0.016`，色 `#2E4A63`），沿用参考图"细线圆角方框界定扩散区"的语言，把宽屏构图锚定住。
  - 面板横向铺满：`x_left/x_right = 0.024/0.976`，`gap=0.0064`。
- **中间"完全噪声"面板的踩坑**：
  - 用 `np.clip` 或过强 tanh（1.06）会把噪声压成**实心色块 + 平顶**，与参考图的密集锯齿观感不符。
  - 解法：① tanh 软压缩阈值放大到 **1.30**（保留尖刺）；② **高噪声帧降采样**（260~340 点）并加"显示增益"列，让尖刺可辨且充满面板；③ 蓝→红渐变改用**分段色标**（0.42 前纯蓝、0.58 后纯红）避免过渡区出现浑浊紫色。
  - `frame_spec` 扩为 5 元组 `(信号幅度, 噪声幅度, 高频权重, 显示增益, 采样点数)`。
