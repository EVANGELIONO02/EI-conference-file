### 源图公式（逐字转录，**均清晰可辨，无「待确认」项**）

原图 `E:\Users\ROG\Downloads\difussion原理图.png`（1440×784）仅含两条公式：

1. 前向扩散（黄带，y≈120–165px）：
   `q(x_k|x_{k-1}) := N(x_k; sqrt(1-β_k) x_{k-1}, β_k I)`
2. 反向去噪（绿带，y≈395–445px）：
   `p_θ(x_{k-1}|x_k) := N(x_{k-1}; μ_θ(x_k,k), σ_θ(x_k,k) I)`

**关键细节**：两条公式的方差项末尾**都带单位矩阵 `I`**（已放大到 6× 逐像素确认，不是 `σ_θ` 遗漏）。
`I` 为 d 维单位矩阵这一点来自原图图注，图注同时说明 β_k∈(0,1)、`𝒩(x;μ,σ)` 为均值 μ、协方差 σ 的高斯分布。
原图未给出 `μ_θ`/`σ_θ` 的显式表达式，因此图中底部"标准扩展式"一栏明确标注为**推导补充（非原图内容）**。

### 关键技术点

1. **6 联幅曲线用"真值前向扩散"生成**，不是手工调噪声：
   `x_k = sqrt(ᾱ_k)·x_0 + sqrt(1-ᾱ_k)·ε`，ᾱ_k 取 **Nichol & Dhariwal 余弦调度**
   `ᾱ_k = cos²(((k/T)+s)/(1+s)·π/2)`，T=1000, s=0.008。
   选步长 `k = [0, 39, 94, 246, 732, 1000]`（噪声标准差 ≈ 0 / .03 / .065 / .16 / .45 / .995），
   使画面退化层次与原图 6 幅**逐幅对应**（前 2 幅近乎干净、中间 2 幅中度失真、末幅纯噪声）。
   → 这比 11-08 那版"手工指定每帧噪声幅度"更自洽，可复现。
2. **软压缩** `y_disp = tanh(y/1.2)` + **高噪声帧降采样**（700/700/700/520/380/260 点），
   避免噪声被 y 轴裁成实心色块、尖刺可辨（沿用 11-08 的经验）。
3. **β_k 调度曲线必须用双 y 轴**（`ax.twinx()`）：β_k 量级 0~0.02，与 ᾱ_k(0~1) 同轴则完全看不见。
4. **版面校验靠程序化检测**，不靠肉眼：
   `t.get_window_extent(renderer)` 取所有文本 bbox → 两两求交 → 报告重叠对。
   最终 **text-text overlaps = 0**。
5. **mathtext 的 `\prod` 带上下限会把文本行高撑到 ~25pt**，在紧凑图例/公式栏里极易撞行；
   图例中 `ᾱ_k` 的释义因此去掉 `\prod`（产品式已在栏 A 给出），并按**每条符号的实际渲染宽度**
   给释义定位（`LEG` 元组第三项），避免宽符号压住后一列。

### 踩坑

1. **matplotlib 3.2.2（Anaconda）**：`ax.text(..., fontproperties=None)` 会抛
   `AttributeError: 'NoneType' object has no attribute 'copy'` —— 只能在该参数非 None 时才传入。
2. `matplotlib.rcParams["mathtext.fontset"]="stix"` + `font.family="STIXGeneral"` 时，
   **中文必须单独指定 `FontProperties(family="Microsoft YaHei")`**（3.2.2 无逐字形回退），
   而 `$\math$` 片段仍走 STIX 字体集 —— 两者可在同一字符串里共存。
3. 3.2.2 的 `divmod(idx, n)` 返回 (商, 余数)；写图例网格时务必确认自己是**行优先**还是**列优先**，
   否则条目顺序与预期错位。

### 真矢量 PPTX 的做法（可复用）

python-pptx 不支持 SVG，需手工改 OOXML：
1. 先用 `add_picture(png)` 生成基底（拿到 `<a:blip r:embed="rIdN"/>`）；
2. zip 里加 `ppt/media/imageN.svg`；
3. `[Content_Types].xml` 注入 `<Default Extension="svg" ContentType="image/svg+xml"/>`；
4. `ppt/slides/_rels/slide1.xml.rels` 加 image 关系（**关系 ID 用标准 `rIdN` 形式**，自定义字符串 ID 虽合法但兼容性差）；
5. slide XML 的 `<a:blip>` 内挂扩展：
   `<a:extLst><a:ext uri="{96DAC541-7B7A-43D3-8B79-37D633B846F1}"><asvg:svgBlip xmlns:asvg="http://schemas.microsoft.com/office/drawing/2016/SVG/main" r:embed="rId3"/></a:ext></a:extLst>`。
   这是 PowerPoint 存 SVG 的标准结构（SVG 为主、PNG 为回退），PowerPoint 2016+ 可缩放/转形状。
6. 校验：zip.testzip() + lxml 解析三个 XML + python-pptx 回读。
